## First use

**NOTE:** _An Appveyor API key is requiered to use online features._

- install the app
- go to appveyor.com > MyProfile > [API-Keys](https://ci.appveyor.com/api-keys)
- create or select a key for a specific account and copy it
- open the app, go to the settings tab
- paste the key into the Appveyor API Token field
